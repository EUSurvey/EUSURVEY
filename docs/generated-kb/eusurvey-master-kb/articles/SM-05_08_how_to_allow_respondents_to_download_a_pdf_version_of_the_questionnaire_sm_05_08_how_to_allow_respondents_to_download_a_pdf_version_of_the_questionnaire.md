## Short Answer

To make a blank PDF version of the questionnaire available to respondents, enable the PDF download option in the survey security settings. After the setting is enabled, respondents can use the Download PDF version option from the right-hand panel of the published survey.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Enable the PDF questionnaire download
2. Open the survey.
3. Go to Properties.
4. Open the Survey Security or Security section.
5. Enable the option Enable PDF download of the survey questionnaire.
6. Save the change.
7. If the survey is already published, apply the changes so they are visible in the published survey.

## Important Conditions / Limitations

* This option provides a blank PDF copy of the questionnaire, not a PDF of a respondent’s submitted answers.
* The respondent accesses the option from the right-hand panel of the survey.
* If the option is not visible to respondents, check that the setting has been enabled and that changes have been applied to the published survey.
