## Intent / Description

Summarize the available ways to manage translations.

## Short Answer

EUSurvey supports translation management through the built-in online translation editor, offline translation by exporting XML/XLS/ODS, DGT translation for EC users, and machine translation.

## Important Conditions / Limitations

* Finish editing and testing the survey before starting translations.
* Translations can be added at any time; it is not necessary to unpublish the survey.
* Tick To Publish if the translation should be published with the survey.
