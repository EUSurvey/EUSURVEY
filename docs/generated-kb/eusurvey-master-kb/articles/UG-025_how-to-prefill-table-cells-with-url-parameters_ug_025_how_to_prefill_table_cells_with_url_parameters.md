## Short Answer

For tables, the URL parameter must include the table question identifier, row identifier and column identifier. The three identifiers are combined in the parameter name, followed by the cell value.

## Important Conditions / Limitations

* Table prefill requires cell-level targeting; a table question identifier alone is not enough.
* Special characters in values must be URL-encoded.
