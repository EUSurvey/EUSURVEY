## Short Answer

EUSurvey supports the last two versions of Microsoft Edge and the latest versions of Mozilla Firefox and Google Chrome.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Use a supported browser: Microsoft Edge, Mozilla Firefox, or Google Chrome.
2. Keep your browser updated.
3. If you experience compatibility issues, try again using one of the supported browsers.

## Important Conditions / Limitations

* Using other browsers may cause compatibility issues.
* Browser support may depend on the browser version used.
