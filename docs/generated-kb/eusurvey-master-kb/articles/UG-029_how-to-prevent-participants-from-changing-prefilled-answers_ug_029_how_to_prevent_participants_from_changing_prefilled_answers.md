# UG-029_how-to-prevent-participants-from-changing-prefilled-answers — UG-029 — How to prevent participants from changing prefilled answers

## Intent / Description

Explain the difference between editable, read-only and hidden prefilled answers.

## Applies To

* Role(s): Survey Owner
* EUSurvey area: Users Guides
* Environment: All
* Article type: How-to
* UI location: Not specified

## Short Answer

Participants can change prefilled values unless the question is set to Read only. If the question is also Hidden, participants cannot see or edit the value.

## Procedure

No detailed procedure provided in source document.

## Important Conditions / Limitations

* Read only prevents editing but still displays the value.
* Hidden plus Read only prevents both viewing and editing by the participant.
