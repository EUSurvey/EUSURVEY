## Intent / Description

Explain how scoring works for free text questions in a quiz.

## Short Answer

For a free text quiz question, define the correct answers and the points awarded. You can award the same number of points for the whole question, or assign points answer by answer.

## Important Conditions / Limitations

* Use “equal to” when a specific text should receive points.
* Use “empty” when no entered text should receive points.
* Use “all other values” only when points are configured for each answer.
