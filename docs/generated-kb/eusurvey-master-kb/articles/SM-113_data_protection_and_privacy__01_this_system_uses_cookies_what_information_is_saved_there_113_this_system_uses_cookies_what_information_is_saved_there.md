## Short Answer

The system uses session 'cookies' to ensure reliable communication between the client and the server.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Therefore, the user's browser must be configured to accept 'cookies', which disappear once the session has been terminated.
2. The system uses local storage to save copies of the participant's input to a survey. This is to ensure there is a backup if the server is not available during submission, the user's computer is switched off accidentally, etc.
3. The local storage contains the IDs of the questions and the draft answers.
4. Once a participant has submitted their answers to the server or has saved a draft on the server, the data is removed from the local storage.
5. There is a checkbox above the survey - 'Save a backup on your local computer (disable if you are using a public/shared computer)' - to disable this feature. In that case, no data will be stored on the used computer.
