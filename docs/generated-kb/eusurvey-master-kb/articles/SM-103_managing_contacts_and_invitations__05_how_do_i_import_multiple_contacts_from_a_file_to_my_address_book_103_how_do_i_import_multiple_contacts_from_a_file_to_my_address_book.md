## Short Answer

To import a list of contacts into the system, EUSurvey offers a wizard that guides you through the import procedure.

Not specified in source document.

## Procedure

1. The following file formats are supported:
2. XLS ODS CSV TXT (with separator).
3. To start the wizard:
4. 1. Select 'Import' from your 'Address Book' page.
5. 2. Select the file in which you have saved your contacts. 3. Specify if your file contains a header row or not. 4. Specify the type of separator you used for CSV and TXT files (the most probable character is suggested by default).
6. As a second step:
7. 1. The system will ask you to map the individual columns to new attributes for your contacts (the mandatory attributes 'Name' and 'Email' must be mapped in order to proceed). 2. Once you click 'Next', the system loads your file into the system, displaying the individual contacts that will be imported. You can unselect individual contacts you don't want to import 3. Click 'Save' to save your contacts to your address book.
