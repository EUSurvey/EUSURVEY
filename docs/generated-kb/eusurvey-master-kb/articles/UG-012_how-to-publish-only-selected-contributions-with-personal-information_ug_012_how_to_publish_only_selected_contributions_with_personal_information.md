# UG-012_how-to-publish-only-selected-contributions-with-personal-information — UG-012 — How to publish only selected contributions with personal information

## Intent / Description

Explain how to publish only contributions where participants agreed to publication with personal information.

## Applies To

* Role(s): Survey Owner
* EUSurvey area: Users Guides
* Environment: All
* Article type: How-to
* UI location: Not specified
* Backend location: Not specified

## Short Answer

Add a consent question asking whether the participant agrees that their contribution can be published. When configuring published results, publish all relevant questions but filter contributions to include only those where the participant selected Yes.

## Important Conditions / Limitations

* This pattern publishes personal information only for the selected contributions that meet the consent condition.
* The survey privacy statement should explain how published results and personal information are handled.
