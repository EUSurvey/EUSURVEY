## Intent / Description

## Short Answer

This message means that the survey author configured the question to require a specific input format, such as a number, a date, or an email address. Dates must be entered in DD/MM/YYYY format.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Check the expected answer type for the question.
2. For a number field, enter a numeric value.
3. For a date field, use the DD/MM/YYYY format.
4. For an email field, enter a valid email address format.
5. Correct the value and submit again.

## Important Conditions / Limitations

* The required format is defined by the survey author.
* For dates, use day/month/year format, for example DD/MM/YYYY.
