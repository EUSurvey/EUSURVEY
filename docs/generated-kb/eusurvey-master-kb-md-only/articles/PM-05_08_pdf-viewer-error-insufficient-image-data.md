# PM-05_08_pdf-viewer-error-insufficient-image-data — 05.08 - PDF viewer error Insufficient Image data

## Intent / Description

Explain why a PDF viewer may show an Insufficient Image data error for a contribution PDF.

## Applies To

* Role(s): Respondent
* EUSurvey area: After contributing
* Environment: All
* Article type: Troubleshooting
* UI location: Not specified
* Backend location: Not specified

## Short Answer

This error can occur when corrupted images were uploaded. The PDF reader may not be able to display the image properly, causing an internal PDF reader error.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Identify whether the contribution contains an uploaded image.
2. Repair the corrupted image if possible.
3. If the image cannot be repaired, remove it and submit or generate the PDF again where possible.

## Important Conditions / Limitations

* The problem is related to how the PDF reader handles corrupted image data.
* Repairing or removing the corrupted image is required to correct the problem.
