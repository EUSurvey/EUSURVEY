# PM-04_02_why-selected-answers-disappear-in-a-matrix-question — 04.02 - Why selected answers disappear in a matrix question

## Intent / Description

Explain why a participant selection may disappear when answering a matrix question.

## Applies To

* Role(s): Respondent
* EUSurvey area: Submitting a contribution
* Environment: All
* Article type: Troubleshooting
* UI location: Not specified
* Backend location: Not specified

## Short Answer

This can happen when the matrix question is configured so that each possible answer can be selected only once. This feature is often used to create a ranking between answers.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Review the matrix question instructions.
2. If the same answer cannot be used more than once, choose a different answer for each row or item.
3. Complete the matrix according to the allowed ranking or selection rules.

## Important Conditions / Limitations

* This behaviour is controlled by the survey author.
* It is not necessarily an error; it may be an intended feature of the question.
