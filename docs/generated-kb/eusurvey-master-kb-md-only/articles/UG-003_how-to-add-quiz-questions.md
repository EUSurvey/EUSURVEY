# UG-003_how-to-add-quiz-questions — UG-003 — How to add quiz questions

## Intent / Description

Explain how quiz-compatible questions are added to a quiz survey.

## Short Answer

In the editor toolbox, quiz-compatible question types are marked with a special icon. Add them by double-clicking the item or using drag and drop. After adding a quiz question, configure its Quiz Properties in the properties pane.
