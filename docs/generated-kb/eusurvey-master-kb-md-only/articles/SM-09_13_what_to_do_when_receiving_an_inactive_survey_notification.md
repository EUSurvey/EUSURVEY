## Short Answer

If you receive an inactivity notification, review whether the survey is still needed. You can export the survey results, export the questionnaire as an .eus file, or update the survey and collect new contributions if it is still in use.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Recommended actions
2. Export survey results, for example as an XLSX file, for archiving.
3. Export the survey questionnaire as an .eus file so it can be imported again later if needed.
4. Review or update the survey, or collect new contributions, if the survey is still in use.
5. If no action is taken and the survey remains inactive, it will be automatically deleted after the notification process.
