# UG-031_how-to-enable-wcag-compliant-mode-for-a-survey — UG-031 — How to enable WCAG-compliant mode for a survey

## Intent / Description

Explain where the WCAG setting is enabled and what it changes.

## Short Answer

Enable the WCAG-compliant questionnaire setting on the survey Properties page under Appearance. When participants open the WCAG-compliant questionnaire, the initial layout uses Enhanced Contrast and multiple choice lists are changed into radio buttons.

## Important Conditions / Limitations

* Participants may change from Enhanced Contrast to Normal view.
* All multiple choice lists are changed into radio buttons.
