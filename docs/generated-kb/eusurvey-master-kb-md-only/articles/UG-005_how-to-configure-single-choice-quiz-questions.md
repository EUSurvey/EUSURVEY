## Short Answer

For single choice quiz questions, EUSurvey uses the possible answers already configured in the question. In Quiz Properties, mark each answer as correct or incorrect and assign points according to the scoring approach.

## Important Conditions / Limitations

* The answer values come from the Possible Answers configured for the question, so they do not need to be entered again in Quiz Properties.
