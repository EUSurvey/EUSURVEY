## Short Answer

You can export your survey's answers using the export feature. This can be useful for further data processing in Excel for example.

## Procedure

1. To export your answers:
2. 1. Go to the 'Results' tab (first screen, the tabular view). 2. Click on the 'Export' button (a popup opens). 3. Enter a name for your export. 4. Select the file format (when export file is generated, you will receive a notification). 5. Go to the 'Exports' tab. 6. Download your file.
