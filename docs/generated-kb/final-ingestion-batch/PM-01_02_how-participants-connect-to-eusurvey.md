# PM-01_02_how-participants-connect-to-eusurvey — 01.02 - How participants connect to EUSurvey

## Intent / Description

Explain which login option participants should use when accessing EUSurvey.

## Short Answer

To connect to EUSurvey, select Login on the EUSurvey homepage. You will be redirected to the EUSurvey login screen, where you must choose the option that matches your situation.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Open the EUSurvey homepage: https://ec.europa.eu/eusurvey/home/welcome.
2. Click Login.
3. On the EUSurvey login screen, choose the option that applies to you.
4. If you work for an EU institution, choose the EU institution option and connect with your EU Login username and password.
5. If you do not work for an EU institution, choose the external user option. External users must have an EU Login account and must have registered a mobile phone for two-factor authentication.

## Important Conditions / Limitations

* External users may need to create an EU Login account: https://webgate.ec.europa.eu/cas/eim/external/register.cgi.
* External users may need to register a mobile phone for two-factor authentication: https://ecas.ec.europa.eu/cas/userdata/mobileApp/manageMyMobileDevices.cgi.
* Two-factor authentication may be required for external participants.
