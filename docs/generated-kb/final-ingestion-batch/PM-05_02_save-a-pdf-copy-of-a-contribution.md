# PM-05_02_save-a-pdf-copy-of-a-contribution — 05.02 - Save a PDF copy of a contribution

## Intent / Description

Explain how participants can receive a PDF copy of their submitted contribution.

## Short Answer

Right after submission, EUSurvey offers the possibility to request an email with a PDF copy of your contribution attached. Use the Get PDF button on the Confirmation page.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Submit your contribution.
2. On the Confirmation page, select Get PDF.
3. Request the PDF copy by email.
4. Save the received PDF for your records.

## Important Conditions / Limitations

* The Get PDF option is available on the Confirmation page after submission.
* The PDF may include your contribution ID.
