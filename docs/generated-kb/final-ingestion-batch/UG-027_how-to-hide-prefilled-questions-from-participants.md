# UG-027_how-to-hide-prefilled-questions-from-participants — UG-027 — How to hide prefilled questions from participants

## Intent / Description

Explain how to submit predefined values without showing them to participants.

## Applies To

* Role(s): Survey Owner
* EUSurvey area: Users Guides
* Environment: All
* Article type: How-to
* UI location: Not specified
* Backend location: Not specified

## Short Answer

To hide a prefilled question, select it in the editor and enable both Read only and Hidden. The value remains visible to the form manager and is submitted with the contribution, but the participant cannot see or edit it.

## Important Conditions / Limitations

* Hidden questions are marked in the editor with a hatched background and a hidden-question icon in the survey preview.
* Number-slider questions with the Slider style cannot be hidden.
