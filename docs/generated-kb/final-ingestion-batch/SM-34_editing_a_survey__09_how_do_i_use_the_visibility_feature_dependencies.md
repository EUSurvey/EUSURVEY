## Short Answer

Using this feature in the editor, you can display and hide elements depending on answers given by participants to either single/multiple choice or matrix questions (see also 'How do I create a questionnaire via the EUSurvey editor?' )

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. By default, all elements are set to always visible, which means that everybody will see the question when answering the survey.
2. To create a dependent question:
3. 1. Add a single/multiple choice or matrix question to your questionnaire. 2. Add further elements to your questionnaire. 3. Select an element that follows a single/multiple choice or matrix element and that should only appear when a specific answer has been chosen. 4. Click the pen icon to edit the visibility settings. All available questions of the type single choice, multiple choice and matrix that are placed above the selected element(s) are displayed, including the question text and the possible answers. 5. Select the answer that, when chosen, will display the selected element. 6. Click 'Apply' to confirm the visibility setting.
4. If multiple elements are selected, you can edit the visibility settings for all of them at once.
5. Note: This modification will only affect the questionnaire on the Test page and in published mode. All elements will still be visible in the editor.
6. When activated, arrows are displayed next to the connected elements to visualise the visibility settings in the Form area. Answers that trigger any element are displayed with an arrow pointing down. Elements that are triggered by any answer are marked with an arrow pointing up.
7. When moving the pointer over the arrows or IDs in the Element properties pane, the connected elements are highlighted in the Form area and Navigation pane.
8. Elements with visibility settings that have been edited will be hidden in the questionnaire until at least one of the configured answers has been selected by the participant when filling in the questionnaire.

## Important Conditions / Limitations

* Note: This modification will only affect the questionnaire on the Test page and in published mode. All elements will still be visible in the editor.
