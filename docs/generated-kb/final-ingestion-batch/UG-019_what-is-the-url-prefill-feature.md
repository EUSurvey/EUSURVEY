## Short Answer

URL prefill lets a form manager send personalized survey links where selected answers are already filled in, such as name, email address or internal categories. It can be used with open surveys, secured surveys, test pages and individual invitation links.

## Important Conditions / Limitations

* The feature works similarly to the Prefilling API Webservice but can be used through URL parameters.
* Prefilled questions can be hidden so that values are submitted without being visible to the participant.
