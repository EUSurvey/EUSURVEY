## Short Answer

Each contact saved in the address book has a variable set of attributes such as 'Country', 'Phone', 'Remarks', etc. You can create a new attribute by editing a contact.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. 1. In the 'Edit Contact' window, open the 'attributes' menu and select 'New...'. 2. A new window will pop up where you can define the name of the new attribute. 3. The newly created attribute will appear as a column in the address book and can also be added to a set of contacts.
