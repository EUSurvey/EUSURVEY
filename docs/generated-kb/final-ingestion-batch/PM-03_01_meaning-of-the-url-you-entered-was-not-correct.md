# PM-03_01_meaning-of-the-url-you-entered-was-not-correct — 03.01 - Meaning of The url you entered was not correct

## Intent / Description

Explain why participants may see the message The url you entered was not correct.

## Applies To

* Role(s): Respondent
* EUSurvey area: Accessing a survey
* Environment: All
* Article type: Troubleshooting
* UI location: Not specified
* Backend location: Not specified

## Short Answer

The message usually means that EUSurvey cannot authorise you to access the survey. This can happen when a previously active invitation has been deleted or deactivated, or when the invitation activation period has expired.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Check that you used the exact access link you received.
2. If the link came from an invitation, verify that the invitation is still valid.
3. If you believe the link should still work, contact the author or owner of the survey.

## Important Conditions / Limitations

* This message can appear even if the link was valid in the past.
* The most common causes are a deleted invitation, a deactivated invitation, or an expired activation period.
