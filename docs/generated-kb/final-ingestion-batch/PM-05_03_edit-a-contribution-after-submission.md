# PM-05_03_edit-a-contribution-after-submission — 05.03 - Edit a contribution after submission

## Intent / Description

Explain under which conditions participants can edit a submitted contribution.

## Applies To

* Role(s): Respondent
* EUSurvey area: After contributing
* Environment: All
* Article type: Troubleshooting
* UI location: Not specified
* Backend location: Not specified

## Short Answer

It depends on how the survey was set up. Some surveys allow participants to reaccess and edit a submitted contribution, while others do not enable this feature.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. Check whether the survey allows reaccess after submission.
2. If reaccess is available, open the edit contribution page: https://ec.europa.eu/eusurvey/home/editcontribution.
3. Enter the Contribution ID that you noted from the Confirmation page or from a related PDF.
4. Edit the contribution if the survey settings allow it.
5. If you did not save the Contribution ID, use the Contact us form: https://ec.europa.eu/eusurvey/home/support.

## Important Conditions / Limitations

* Editing after submission is controlled by the survey configuration.
* The Contribution ID is required to identify the submitted contribution.
* If the survey does not allow reaccess, you may not be able to edit the submitted contribution.
