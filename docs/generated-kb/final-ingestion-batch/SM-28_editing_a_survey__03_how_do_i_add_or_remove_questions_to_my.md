## Short Answer

To add new elements to your form or remove existing ones, first open the editor.

## Prerequisites / Required Permissions

Not specified in source document.

## Procedure

1. In the editor you will find a Toolbox of available elements on the left and the Form area in the middle of the screen. The elements contain default texts, with the name of the element displayed as the question text. To add a new element (question, text field, image, etc.), select one from the Toolbox. You can add elements either by using the drag-and-drop feature or by double-clicking them.
2. To remove an element from the form, you can click the element to select it. Click on 'Delete'; as soon as you have confirmed, the element will be removed from the questionnaire.
3. See also 'How do I create a questionnaire via the EUSurvey editor?'
