# UG-049_how-to-use-the-complexity-indicator — UG-049 — How to use the complexity indicator

## Intent / Description

Explain what the complexity indicator shows and why it matters.

## Applies To

## Short Answer

The complexity indicator shows how complex the questionnaire is. Adding many elements or visibility settings increases complexity. If complexity is too high, the published questionnaire can become slow for participants.
